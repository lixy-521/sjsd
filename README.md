# 山经书店 · 消失的买家

一个中文文字解谜 ARG（Alternate Reality Game）。调查一间表面是教辅书店、背后却在进行「认知数据交易」的店铺。

> 有些教辅，不教你知识，教你成为别人。

## 开始

直接打开根目录的 `index.html`（或用任意静态服务器托管本目录）。
入口页是一个仿微信的聊天窗口，刘天清的脚本对话会陆续发来几个网页链接；
点击链接卡片会在**新标签页**打开对应页面。

> 公众号「山经海籍」与小程序「山经海集」在**微信端**实现，本仓库不含其网页版与文稿。

## index2：把刘天清换成真 AI

`index2.html` 是 `index.html` 的平行版本，只改了「谁来回话」这一件事：

- **开场完全一样**：13 条消息 + 3 张链接卡片，逐条与 `index.html` 一致（含开头的图片和末尾两条
  「回复小助手」脚本回复）。开场这部分仍是写死的，不由模型生成。
- **玩家发出第一条消息之后，回复改由 AI 生成**，并且把**整段开场对话作为上下文**一起发给模型
  （开场里玩家的话标成 `user`、刘天清的话标成 `assistant`，图片转成「（发来一张图片）」占位），
  所以模型知道前面聊过什么，能接着往下接。
- **接入窗口**：右上角或输入框左边的 ⚙ 打开，可拖动、位置会记住。要填的就三样——
  **接口地址 base_url、模型名 model、API Key**（外加温度、流式开关、超时）。
  这是 OpenAI 兼容的 `chat/completions` 接口，所以 OpenAI / DeepSeek / 月之暗面 / 硅基流动 /
  本地 Ollama & LM Studio 都能用。地址会自动补 `/v1/chat/completions`，填到哪一级都行。
  有「测试连接」按钮当场验证。
- **配置只存在本机** localStorage（`lbyz_ai_config_v1`），聊天记录也另存一份
  （`lbyz_chat_history_v2_ai`），与 `index.html` 的记录互不干扰。
- **严格在角色内**：系统提示词写死了刘天清的身份、已知情情报、口吻，以及「不知道就说不知道、
  绝不编造线索、不给谜题答案、不承认自己是 AI」。玩家也能在「高级设置」里自己改提示词
  （改了可能剧透，所以默认折叠并加了提示）。
- **AI 可以发链接**：让它单独写一行 `[[链接:文字|地址]]`，页面会把它渲染成和开场一样的链接卡片，
  正文里那行本身去掉。只放行站内路径，避免乱发外部网址。
- **刘天清可以发图片**：他只能从站内已有的三张工位照片里挑——
  舒巍 `[[图片:sw]]`、余皎颖 `[[图片:yjy]]`、陈超武 `[[图片:ccw]]`。
  让它单独写一行这种标记，页面会把它渲染成聊天里的一张图片气泡（和开场那张图一样的样式，
  可点击放大），正文里那行本身去掉；一次可以发多张，也能和链接卡片混着发。
  白名单外的路径一律不认，避免模型乱指文件。
- **出错兜底**：401 / 404 / 429 / 超时 / 空回复 / 网络失败都给中文说明并附「重试」按钮；
  浏览器直连第三方接口需要对方允许跨域（CORS），没开的话会在提示里点出来。

> ⚠️ `index2.html` 是给玩家自己接入模型玩的附加版本，**不影响 `index.html` 的原有解谜流程**；
> 两个文件各自独立，改动其一不会影响另一个。

### 时间体系

- **全局「现在」= 日期固定 `2026-07-28`，时刻跟着真实时钟走。**
  后台三页页眉与 `northland/lab.html` 页脚挂同一套时钟（`#sysclock` / `#clock`），日期写死、秒数每秒刷新。
  实现在 `admin-log.js` 的 `FIXED_DATE` + `nowStr()`；实验室那页是因为 2025-11-25 之后数日被查封、官网从此停更。
- **玩家操作写入的日志时间戳同样是「日期 2026-07-28 + 真实时刻」**，所以玩家自己在真实世界的任何日期游玩，
  后台里看到的时间都落在剧情当天。
- **项目倒计时**：董新飞设的是 **1 小时 12 分钟**，设置时刻 = **进入陈超武页面那一刻**的前 1 小时，
  所以第一次进后台看到的是 **12 分钟**，之后按真实时间递减，减到 `00:00:00` 停住。
  基准时刻记在 localStorage `sjsd_cd_anchor`（`admin-log.js` 的 `sessionStart()` 在第一次打开后台时写一次，
  之后刷新、来回切页面、重进陈超武页都不会重置）；**四个结局页（含结局零）载入时 `clearSession()` 会连同
  `sjsd_session_start` 与落档标记一起清掉**，重新开始会重新计 12 分钟，系统原有记录里董新飞那三条的时间戳也跟着重排。
  正常流程（姜游亮 → 陈超武 → 董新飞）下，第一次打开后台就是进入陈超武页面，两者是同一时刻。
  若玩家跳过陈超武先开了别的后台页面，基准就退化成那一刻起算，之后再进陈超武也不会重置。
  若基准落在 `00:00–01:00`，那几条会一起退到 **2026-07-27**（跨午夜）。
- `admin-data.js` 的 `baseLog` 里董新飞那三条用占位符 `@DONG_LOGIN@` / `@DONG_VISIT@` / `@COUNTDOWN_SET@`，
  由 `admin-log.js` 的 `resolveTs()` 在落地时换算成实际时间戳；`originalLog()` 走同一套换算，
  所以「当前记录 vs 原有记录」的逐条比对不会因为时间戳而假失败。
