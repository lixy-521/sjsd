## 二、视觉规范

### 通用
- 字体：`"PingFang SC","Microsoft YaHei",-apple-system,sans-serif`
- 等宽（技术/后台/论文）：`"Courier New","SimSun",monospace`
- 页面主体宽度 640px 居中（论坛/公众号）；学校官网 1100px。
- 顶部返回栏统一：左侧 `←` 返回上一级，右侧/中间标题。

### 主题色板
| 场景 | 背景 | 卡片 | 主色 | 强调 |
|------|------|------|------|------|
| 平台/学校（浅蓝） | `#f0f2f5` | `#fff` | `linear-gradient(135deg,#1a3a5c,#2d5a8a)` | `#2d5a8a` |
| 论坛（灰） | `#f2f2f2` | `#fff` | `#2d5a8a` | `#c0392b` |
| 公众号（微信） | `#ededed` | `#fff` | `#07c160` | `#576b95`（链接蓝） |
| 小程序（微信电商） | `#f5f5f5` | `#fff` | `#07c160` | `#e54d42`（价格红） |
| 北境实验室（冷科技） | `#0a0e14` | `#0e141c` | 青色 `#3fa9c9` | `#8b0000` |
| 内部后台（古早简陋） | `#c0c0c0`/`#111` 表格风 | `#e8e8e8` | `#000080`（老式链接蓝） | `#800000` |
| 认知强化（黑红） | `#0a0a0a` | `#0e0e0e` | `#5c0000` | `#cc6666` |

### 公众号文章页规范
- 顶部：`#ededed` 返回栏 + 订阅号名「山经海籍」。
- 文章头：标题 20px 加粗 `#222`，下方灰色 12px「山经海籍 · 2026-xx-xx」。
- 正文 16px / line-height 1.8 / `#333`，段落 `text-indent:2em`。
- 底部：阅读量、点赞、在看、留言区。
- **已删除文章**（[B]/[H]）：正文区显示居中的「该内容已被发布者删除」+ 灰色感叹号，不可继续阅读内容。

### 小程序页规范
- 顶部导航条 + 微信胶囊按钮占位。
- 商品卡：封面占位（纯色块 + emoji/书名文字）、书名、`¥xx` 红色、销量。
- 底部 tab 栏：首页 / 分类 / 学习方法 / 我的。

### 后台页规范（古早系统）
- 顶部纯色条 + 简单表格，`border:1px solid #808080`，彩色链接、`marquee` 式滚动公告可选。
- 登录页极简：两个输入框 + 按钮，说明文字写在页面下方。
